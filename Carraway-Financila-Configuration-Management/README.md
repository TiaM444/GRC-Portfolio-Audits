Configuration Management Policy: Carraway Financial Bank (CFB)

📌 Project Overview
This project involved developing a comprehensive Configuration Management Policy for a fictional financial institution, 
Carraway Financial Bank (CFB). The policy was designed to establish standardized security baselines and monitoring
practices to protect system integrity and ensure regulatory compliance.


🛡️ Regulatory Alignment
To meet the high security standards of the financial sector, this policy was mapped to the following frameworks:

NIST SP 800-53: Ensuring robust federal-grade security controls.

PCI-DSS: Protecting payment card data and maintaining secure network configurations.

🗝️ Key Features
Baseline Management: Established requirements for documented security settings 
across all servers, databases, and cloud infrastructure.

Change Control: Outlined a formal process for requesting, testing, and approving 
configuration changes to prevent unauthorized modifications.


Continuous Monitoring: Defined procedures for daily monitoring and automated alerts to detect "configuration drift".


Roles & Responsibilities: Detailed the specific duties of the CISO, System Owners, and IT Operations to ensure clear accountability.
