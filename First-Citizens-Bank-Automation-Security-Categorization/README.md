System Categorization: First Citizens Bank Automation Integration

📌 Project Overview

This project was completed as part of the WiCyS (Women in Cybersecurity) GRC Intensive program. The objective was to perform a formal Security Categorization for an automation integration platform used by First Citizens Bank.

🛡️ Framework & Methodology

The categorization was conducted using the NIST Risk Management Framework (RMF), specifically:

NIST SP 800-60 Vol. 2: Mapping information types to security categories.

FIPS 199: Determining the security impact levels (Low, Moderate, High) for the CIA Triad (Confidentiality, Integrity, and Availability).

🔍 Key Objectives

Information Type Identification: Classified the types of financial and personal data processed by the automation platform.

Impact Analysis: Evaluated the potential impact on bank operations, assets, and individuals if the system's security was compromised.

Security Baseline Selection: Provided the foundation for selecting appropriate security controls based on the "Moderate" or "High" impact rating.
